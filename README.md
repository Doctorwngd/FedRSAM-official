# FedRSAM

Official repository for **Focus on Where You Aggregate: Restricted SAM for Non-IID Federated Learning** (NeurIPS 2026).

**Authors:** Haotong Wen, Junkang Liu, Yi Xu, Xiao Liu, Longkun Guo, and Kewen Liao.

FedRSAM restricts local sharpness-aware perturbations to an aggregation-relevant cone constructed from the previous global update direction and coordinate-wise client-update variance. This focuses local loss flattening on regions relevant to global aggregation under non-IID data.

## Code release

The public implementation is being organized. Training and evaluation scripts, environment setup, and reproduction instructions will be added to this repository.
